# ADR 0002: Synchronous Ingestion and Deduplication Strategy

## Context

Jobs can be discovered through various channels: direct posting URLs, pasted descriptions, and aggregators. Ingesting cross-posted listings without deduplication wastes inference tokens and pollutes the candidate inbox. However, implementing background feed scrapers in Phase 1 adds unnecessary concurrency and crawler maintenance complexity.

## Decision

Limit Phase 1 ingestion to synchronous, user-triggered entry points: direct text pasting and single-URL scraping.

Deduplication will occur prior to deterministic filtering and AI evaluation. The system computes a deterministic `dedupeKey` generated by creating a SHA-256 hash of normalized, lowercased alphanumeric tokens from `companyName` and `roleTitle`, combined with normalized URL identity when present. If an incoming job matches an existing `dedupeKey`, the ingestion updates metadata if newer without re-triggering fit scoring.

## Consequences

- Predictable execution flow with zero unprompted background scraping.
- Eliminates redundant AI scoring requests on cross-posted roles.
- Automated RSS and continuous feed polling are cleanly isolated to Phase 2.
